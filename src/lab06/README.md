# ЛР6 — CLI-утилиты на Python (argparse)

## Цель работы

Разработка консольных утилит для работы с текстовыми файлами и преобразования данных между форматами JSON, CSV и XLSX. Изучение библиотеки `argparse` для обработки аргументов командной строки.

## 1. Работа с текстовыми файлами

### Модуль `src/lab06/cli_text.py`

В модуле реализованы две основные функции: `cat()` и `stats()`.

### Функция `cat(input_path: str, n: bool) -> None`

Функция выводит содержимое указанного файла в терминал построчно.

Предусмотрены два режима работы:
- Без дополнительного параметра — отображение текста без изменений.
- С флагом `-n` — вывод содержимого с нумерацией строк.

**Пример запуска с нумерацией строк:**

```bash
python -m src.lab06.cli_text cat --input data/samples/people.csv -n
```

## 2. Конвертация файлов

### Модуль `src/lab06/cli_convert.py`

В данном модуле реализована консольная программа для преобразования файлов различных форматов.

Для обработки команд и параметров используется библиотека `argparse`.

Программа поддерживает три операции:

1. `json2csv` — преобразование JSON в CSV.
2. `csv2json` — преобразование CSV в JSON.
3. `csv2xlsx` — преобразование CSV в Excel (XLSX).

Для каждой команды указываются:
- `--in` — путь к исходному файлу.
- `--out` — путь для сохранения результата.

### 2.1. Преобразование JSON в CSV

Для выполнения операции используется команда:

```bash
python -m src.lab06.cli_convert json2csv --in data/lab06/samples/people.json --out data/lab06/out/people.csv
```

В результате создаётся CSV-файл с данными из исходного JSON. Первая строка содержит названия столбцов.
