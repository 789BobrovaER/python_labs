**Работа со списками**

* `len(список)` — возвращает количество элементов. Использовали для проверки пустого списка и для длины строки матрицы.
* `.append(x)` — добавляет элемент в конец списка. Использовали для сборки результата в `flatten`, `transpose` и `col_sums`.
* `список[i]` / `матрица[i][j]` — доступ к элементу по индексу. В матрице сначала номер строки, потом номер столбца.
* `список[1:]` / `[1:3]` — срез: часть списка от одного индекса до другого (правая граница не включается). Использовали для обхода без первого элемента и для имени с отчеством.
* `list(set(nums))` — `set` убирает дубликаты, `list` превращает результат обратно в список. Использовали в `unique_sorted`.
* `sum(список)` — возвращает сумму элементов. Использовали в `row_sums`.
* `[sum(m) for m in mat]` — генератор списка: короткая запись цикла, который собирает новый список. Использовали в `row_sums`.

**Циклы и ветвления**

* `for x in список:` — перебирает элементы по одному. Использовали в `min_max` и `flatten`.
* `for i in range(n):` — перебирает числа от 0 до `n-1`. Использовали, когда нужен индекс: в пузырьковой сортировке и в обходе столбцов.
* Вложенный цикл — внутренний цикл выполняется целиком на каждом шаге внешнего. Использовали в `transpose`, `col_sums` и `unique_sorted`.
* `if` / `else` — ветвление: выполняет блок, если условие истинно. Использовали для сравнения `x < lo` и проверок на пустоту.
* `all(условие for x in ...)` — возвращает `True`, если условие верно для всех элементов. Использовали в `check` для проверки, что все строки одной длины.
* `0 <= gpa <= 5` — цепочка сравнений, как в математике. Использовали для проверки диапазона GPA.

**Работа со строками (методы)**

* `.split()` — разбивает строку по пробелам на список слов и убирает лишние пробелы. Использовали для разбора ФИО и группы.
* `.upper()` — переводит строку в верхний регистр. Использовали для инициалов.
* `" ".join(список)` — склеивает список строк через разделитель. Использовали вместе с `split()` для схлопывания пробелов в группе.
* `строка[0]` — первый символ строки. Использовали для получения первой буквы имени.
* `+` для строк — склеивает строки. Использовали для сборки инициалов `И.И.`

**Форматирование вывода (f-строки)**

* `f'текст {переменная} текст'` — подставляет значение переменной прямо в строку.
* `{число:.2f}` — выводит число с 2 знаками после запятой. Использовали для GPA в `format_record`.

**Функции и ошибки**

* `def имя(параметры) -> тип:` — объявление функции. Аннотации типов (`list[float | int]`) подсказывают, что принимает и что возвращает функция.
* `return` — отдаёт результат и завершает функцию. Функции в лабе возвращают результат, а не печатают.
* `return lo, hi` — возвращает сразу два значения (кортеж).
* `raise ValueError(...)` — бросает ошибку, если значение не подходит (пустой список, рваная матрица, GPA вне диапазона).
* `raise TypeError(...)` — бросает ошибку, если тип неверный (элемент не список и не кортеж).
* `isinstance(x, (list, tuple))` — проверяет, что объект имеет один из указанных типов. Использовали в `flatten`.
* Docstring — строка в тройных кавычках сразу после `def`, описывает функцию. Обязателен в лабах.

**Присваивание и кортежи**

* `a, b = b, a` — обмен значений без третьей переменной. Использовали в пузырьковой сортировке.
* `fio, group, gpa = rec` — распаковка кортежа в отдельные переменные. Использовали в `format_record`.
* `lo = hi = nums[0]` — одно значение сразу двум именам. Использовали для начальных минимума и максимума.
* `Record = tuple[str, str, float]` — псевдоним типа: даёт имя кортежу-записи студента.

**Запуск и проверка**

* `if __name__ == "__main__":` — блок выполняется только при прямом запуске файла, но не при импорте. Использовали для тестов под функциями.
